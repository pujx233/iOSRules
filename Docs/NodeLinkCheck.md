# 代理链路检测

1. 在 Sub-Store 的订阅设置中，添加「节点操作 → 脚本操作 → 链接」，使用原作者的 [Operator.js](https://raw.githubusercontent.com/I-am-R-E/Functional-Store-Hub/Master/NodeLinkCheck/Sub-Store/Operator.js)。
2. 在 Loon 中订阅 Sub-Store 生成的节点。
3. 长按节点，在菜单中运行代理链路检测。

如提示「请先从Sub-Store订阅」，请先完成前两步以生成节点映射。
